# 스윗미 (swithme) - 활동 시간 관리 대시보드

공부·운동·업무·자기개발 등 **모든 활동 시간을 측정·기록하고 회고 데이터로 분석**하는 PWA입니다. 학습 도메인에 한정되지 않습니다.

## 주요 기능
* **대시보드:** 목표 달성 및 하루 회고 관리.
* **타이머 / 스톱워치:** 카테고리별 활동 시간 측정 (일시정지·재개, 앱 재진입 시 상태 복원).
* **타임테이블:** 24시간 × 10분 단위 그리드에 활동 기록·계획 표시. 요일별·매일 반복 습관 시드 지원.
* **카테고리:** 카테고리별 색상 지정 및 관리.
* **분석:** 종합 점수, 카테고리별 트렌드 그래프, 인사이트, 처방전.
* **계정 · 클라우드 동기화:** 구글·이메일 로그인 시 활동 데이터를 계정에 저장·복원 (기기 간 이동, 브라우저 데이터 삭제 후 복구). **로그인 없이 게스트로도 전 기능 사용 가능.**
* **사탕(토큰):** 분석 기능의 소비 재화. 매달 무료 1개 지급. 현재 분석 잠금은 꺼져 있음.

## 🌟 스윗미만의 차별점 (Core Differentiator)

스윗미는 단순한 계획 수립 도구를 넘어, **유저의 활동 패턴을 데이터로 분석하고 개선 방안을 제시**하는 계획·실행·분석 루프 도구입니다.

*   **실시간 패턴 분석:** 활동 시간, 집중 밀도, 루틴 일관성 데이터를 통해 효율을 진단합니다.
*   **맞춤 처방:** 종합 점수·최약 카테고리·최약 요일을 종합해 개선 방안을 제시합니다.
*   **메타인지 강화:** 데이터 시각화 리포트로 유저가 자신의 강점과 약점을 객관적으로 파악하도록 돕습니다.

## 실행 방법

본 프로젝트는 `Vite`를 사용하도록 구성되었습니다. 로그인·동기화 기능을 쓰려면 Firebase 설정 키를 담은 `.env`가 필요합니다(없어도 게스트 모드로 실행됩니다).

1. **의존성 설치**
   ```bash
   npm install
   ```

2. **개발 서버 실행**
   ```bash
   npm start
   ```
   브라우저에서 `http://localhost:5173` 접속.

## 개발 도구

### 린트 & 포매팅
```bash
npm run lint          # ESLint 검사
npm run lint:fix      # ESLint 자동 수정
npm run format        # Prettier 포매팅
```

### 테스트
```bash
npm test              # Vitest watch 모드
npm run test:run      # 단일 실행
```

### 문서 통합본
```bash
npm run docs          # docs/ 등 읽기용 문서 → 문서요약.html 재생성
```
> `문서요약.html`은 자동 생성물입니다. 직접 수정하지 말고 원본 마크다운을 고친 뒤 위 명령으로 다시 만드세요.

### 빌드 (PWA 포함)
```bash
npm run build         # 프로덕션 빌드 (Service Worker + manifest 자동 생성)
npm run preview       # 빌드 결과 로컬 미리보기
```

> PWA 아이콘(`public/pwa-192x192.png`, `public/pwa-512x512.png`)은 별도 준비 필요. 현재 `public/favicon.svg`가 placeholder로 제공됩니다.

## 프로젝트 구조
* `index.html`: 메인 대시보드 구조.
* `style.css`: 전체 스타일링 (Glassmorphism 적용).
* `js/`: 핵심 로직 (상태 관리, UI, 타이머, 인증, 동기화 등).
* `tests/`: Vitest 단위 테스트.
* `firestore.rules`: Firestore 보안 규칙 (계정별 데이터 접근 제한).
* `.env`: Firebase 설정 등 환경 변수 (버전 관리 제외).
* `docs/`: 기획·PRD·로드맵·할 일 문서.
* `vite.config.js`: Vite + PWA + Vitest 통합 설정.
* `eslint.config.js`: ESLint Flat Config (ES Module 기반).
* `.prettierrc`: Prettier 포매팅 규칙.
* `CLAUDE.md`: 에이전트 작업 가이드 (AI 협업용).
